## 2. Chemistry Context

### Lipid

| Field | Type | Rules |
|------|-----|--------|
| `id` | UUID | PK, auto-generated |
| `name` | string | optional |
| `smiles` | string | must be a valid SMILES |
| `inchi` | string | computed from SMILES |
| `molecular_weight` | float | 200–2000 Da |
| `logP` | float | -2 to 15 |
| `lipid_class` | enum | `ionizable`, `helper`, `sterol`, `peg` |
| `structure_3d` | binary | SDF format |
| `is_synthetic` | boolean | whether generated by AI |
| `source_job_id` | UUID | FK → PredictionJob (nullable) |

**Business rules:**
- SMILES must be parseable by RDKit
- AI-generated lipids must have `is_synthetic=true`
- Every lipid must be used in at least one Formulation or explicitly archived

### Formulation

| Field | Type | Rules |
|------|-----|--------|
| `id` | UUID | PK |
| `name` | string | — |
| `cargo_type` | enum | `mRNA`, `siRNA`, `DNA`, `CRISPR` |
| `cargo_sequence` | text | nucleotide sequence |
| `np_ratio` | float | 1–12 |
| `target_tissue` | enum | `spleen`, `liver`, `lung`, `tumor`, `custom` |
| `ph` | float | 4.0–8.0 |
| `lipid_ratios` | LipidRatio[] | sum of molar_ratio = 1.0 |

### LipidRatio

| Field | Type | Rules |
|------|-----|--------|
| `lipid_id` | UUID | FK → Lipid |
| `molar_ratio` | float | 0–1, sum = 1.0 |
| `role` | enum | `ionizable`, `helper`, `sterol`, `peg` |

**Business rules:**
- Every Formulation must have exactly one ionizable lipid
- The PEG ratio must not exceed 5%
- The N/P ratio for mRNA must be between 2–8

## 3. Clinical Context

### Patient (anonymous)

| Field | Type | Rules |
|------|-----|--------|
| `id` | string | format `GT_XXXX` |
| `age` | int | 10–80 |
| `gender` | enum | `male`, `female`, `other` |
| `disease_severity` | float | 1.0–10.0 |
| `disease_type` | string | — |
| `immune_status` | enum | `normal`, `compromised`, `autoimmune` |
| `is_synthetic` | boolean | synthetic or real data |

**Privacy rules:**
- No PII (name, national ID, address) is stored
- Real data must be anonymized
- Synthetic data must have `is_synthetic=true`

### TreatmentOutcome

| Field | Type | Rules |
|------|-----|--------|
| `patient_id` | string | FK → Patient |
| `formulation_id` | UUID | FK → Formulation (nullable) |
| `time_to_recovery_days` | float | > 0 |
| `event_status` | boolean | 1 = event occurred |
| `treatment_response` | boolean | 1 = positive response |
| `toxicity_level` | float | 0–4 |
| `cytokine_storm` | boolean | — |

**Event definition:**
- Complete recovery
- Tumor burden reduction ≥ 30%
- Disease relapse

### AdverseEvent

| Field | Type | Rules |
|------|-----|--------|
| `patient_id` | string | FK |
| `event_type` | enum | `cytokine_storm`, `hepatotoxicity`, `nephrotoxicity`, `other` |
| `severity` | enum | `mild`, `moderate`, `severe`, `life_threatening` |
| `onset_day` | int | day since treatment start |

## 6. Value Objects

### HazardRatio

```python
@dataclass(frozen=True)
class HazardRatio:
    variable: str
    coefficient: float
    confidence_interval: tuple[float, float]
    p_value: float
```

### MolecularDescriptor

```python
@dataclass(frozen=True)
class MolecularDescriptor:
    molecular_weight: float
    logP: float
    tpsa: float          # Topological Polar Surface Area
    hbd: int             # Hydrogen Bond Donors
    hba: int             # Hydrogen Bond Acceptors
    rotatable_bonds: int
```

### RankingScore

```python
@dataclass(frozen=True)
class RankingScore:
    efficacy: float       # 0–1
    safety: float         # 0–1
    synthesizability: float  # 0–1
    cost: float           # 0–1 (inverse of cost)
    final: float          # weighted sum
```

## 7. Domain Events

| Event | Trigger | Payload |
|-------|---------|---------|
| `LipidDesigned` | The generative model produced a new lipid | lipid_id, job_id |
| `FormulationCreated` | A new formulation was recorded | formulation_id |
| `PredictionCompleted` | The prediction job finished | job_id, metrics |
| `SyntheticDataGenerated` | A synthetic dataset was generated | dataset_id, n_samples |
| `AdverseEventDetected` | An adverse event was detected | patient_id, event_type |
| `ModelDeployed` | The model went to production | model_version_id |
