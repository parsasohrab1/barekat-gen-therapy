# barekat-gen-therapy

هدف: طراحی یک پلتفرم محاسباتی برای طراحی و بهینه‌سازی ناقل‌های ژنی (به ویژه ناقل‌های لیپیدی) با استفاده از هوش مصنوعی.

ورودی‌ها: ساختار شیمیایی لیپیدها و مواد تشکیل‌دهنده، داده‌های تجربی برون‌تنی و درون‌تنی از کارایی انتقال ژن و سمیت، و اطلاعات مربوط به بافت هدف (مانند طحال یا سلول‌های سرطانی).

پردازش: مدل‌های یادگیری عمیق مانند شبکه‌های مولد (مانند نوعی GPT) برای طراحی کتابخانه‌های وسیع از لیپیدهای جدید با ساختار سه‌بعدی بهینه. این مدل‌ها از داده‌های موجود برای پیش‌بینی کارایی و ایمنی ناقل‌های پیشنهادی استفاده می‌کنند .

خروجی‌ها: لیست اولویت‌بندی‌شده از کاندیداهای لیپیدی برای سنتز و آزمایش، پیش‌بینی کارایی انتقال ژن در بافت‌های مختلف، و مسیرهای سنتز پیشنهادی.

محدودیت‌های کلیدی: دسترسی به پایگاه‌های داده بزرگ و با کیفیت از آزمایشات ژن درمانی، توانایی پیش‌بینی سمیت و پاسخ ایمنی، و یکپارچه‌سازی با ربات‌های خودکار برای انجام آزمایشات با کارایی بالا.

فرمول تولید داده‌های سنتتیک
با توجه به کمیاب بودن داده‌های واقعی ژن درمانی، رویکردی که دانش را از یک مدل آماری معتبر (مانند مدل کاکس) تقطیر (Distill) می‌کند، مانند چارچوب CK4Gen، می‌تواند مفید باشد .

فرمول پیشنهادی برای داده‌های پاسخ به ژن درمانی:

تعریف متغیرهای بالینی: سن، جنسیت، نوع بیماری، وضعیت ایمنی، و سایر متغیرهای تأثیرگذار بر موفقیت درمان.

تعریف پیامدها: متغیر اصلی "زمان تا بهبودی" (Survival Time) و وضعیت رویداد (Event) است که در آن "رویداد" می‌تواند بهبودی کامل، کاهش بار تومور یا عود بیماری باشد.

مدل‌سازی با مدل کاکس (CoxPH): با استفاده از داده‌های واقعی محدود موجود، یک مدل کاکس برازش می‌شود تا نسبت مخاطره (Hazard Ratio) برای هر متغیر بالینی تخمین زده شود .

تولید داده‌های جدید: یک شبکه عصبی (بخش SynthNet در CK4Gen) با استفاده از دانش تقطیر شده از مدل کاکس آموزش داده می‌شود تا نمونه‌های جدیدی تولید کند که توزیع زمان تا رویداد و روابط بین متغیرها را به طور معنی‌داری حفظ کند. برای حفظ ساختار و حریم خصوصی، این رویکرد از خوشه‌بندی برای حفظ پروفایل‌های متمایز ریسک بیماران استفاده می‌کند و از "محو شدن" داده‌ها جلوگیری می‌نماید .
